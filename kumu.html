3 Publication Network Maintenance

Elements: The publications (i.e. each row of the dataset because there is only one value for “Type”)

Type: There is one type of element in the dataset, which are publications

Tags/Element Type The columns that are used to categorize information about the elements, can contain multiple descriptors (i.e. method, theme)

3.1 Adding Column in linked data

  1. Add the column in the main spreadsheet
  2. Refresh network map page
  3. Open the hamburger menu in the top left corner and go to fields
  4. Under Relevance > Element Types > Publication, click edit at the bottom of the list and select the added column titles
  5. Re-run metrics

3.2 Adding Pub Type

  1. Open advanced editor

3.3 Adding Filter Category

3.4 Running Updated Metrics

Once the kumu_publication_network google sheets has been updated, you will need to re-run the metrics that scale the elements according to their frequency in the dataset.

  1. Refresh the Kumu Map
  2. Select all buttons under Connect by.... We want all element types to appear on the map.
  3. Click the erlenmeyer flask icon in the bottom right corner that is labeled Metrics
  4. Click Social Network Analysis
  5. Choose indegree as the metric and click Discover the Influencers
  6. Now deselect all buttons under Connect by... so that the only the publication elements appear on the map
  7. Choose indegree and again click Discover the Influencers
    1. This process resets the indegree value (i.e. how many connections between elements) to zero for the publications so that they have a standard element size. The recalculated metrics for the other element types (method, theme, etc.) will be retained and rescaled according to the dataset updates.

  element-font-size: 400; #larger than defauly font size (under map bubbles) to help with accessible visibility
  background-color: white; #map background is white
  font-cutoff: 1;

  connection-length: 400; #forces longer connection lines to create visual space/avoid tight overlapped clusters

  selection-color: red; #sets the colored ring that will appear on a selected element (default is red!)

}
